# Agentes del chatbot

Esta aplicación es un prototipo web dentro de KINAI. Antes de modificarla, leer `../../AGENTS.md` y este README.

- No añadir claves al frontend, `localStorage`, commits o archivos de ejemplo.
- Las credenciales de Anthropic y Hugging Face pertenecen al entorno serverless de despliegue.
- No cambiar el Space o el modelo por defecto sin actualizar `../../docs/models/asr.md`.
- Los cambios de despliegue, dependencias o funciones serverless requieren revisión cuidadosa.
- Ejecutar `npm run typecheck` y `npm run build` cuando el cambio afecte la aplicación.
- Abrir PR desde una rama propia; no hacer push directo a `main`.
