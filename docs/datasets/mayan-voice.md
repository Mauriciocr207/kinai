# Dataset `mau-cr/mayan-voice`

El corpus maya yucateco está restringido por el momento. El repositorio documenta manifiestos y derivados autorizados, pero no supone que el audio original pueda redistribuirse.

La ficha completa debe registrar procedencia, consentimiento, fuentes, hablantes, transformaciones, licencia, proceso de solicitud de acceso y usos permitidos. Los identificadores sensibles no deben copiarse a esta documentación pública.
