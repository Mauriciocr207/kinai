# KINAI Lab

Kinai es la plataforma para investigar y construir un asistente de voz y tecnología de voz en maya yucateco.

El laboratorio reúne cuatro capas:

1. **Investigación:** corpus, análisis, entrenamiento y evaluación.
2. **Tecnología:** ASR, TTS, procesamiento de audio y datos.
3. **Aplicaciones:** chatbot, demos y futuras interfaces.
4. **Infraestructura:** reproducibilidad, almacenamiento, hardware y colaboración con agentes.

El asistente final es la dirección del proyecto, pero cada subproducto debe poder documentarse y reutilizarse por separado.
