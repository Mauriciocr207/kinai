# TTS maya yucateco

## Modelo disponible

- Hugging Face: [`mau-cr/mms-tts-yua-6voces`](https://huggingface.co/mau-cr/mms-tts-yua-6voces)
- Lengua objetivo: maya yucateco
- Voces: seis, según la publicación del modelo

La integración en una aplicación todavía debe documentarse y validarse. No se debe presentar como parte funcional del chatbot hasta comprobar instalación, inferencia, pronunciación, latencia y licencia.

El ejemplo de uso vivirá en `examples/tts/` y deberá indicar hardware, dependencias, voz seleccionada, salida esperada y limitaciones.
