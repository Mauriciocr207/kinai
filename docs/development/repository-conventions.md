# Convenciones del repositorio

- README raíz: entrada al laboratorio.
- README de proyecto: instrucciones operativas locales.
- `docs/`: documentación transversal.
- `examples/`: ejemplos cortos y verificables.
- `projects/`: investigación y experimentos.
- `apps/`: aplicaciones.
- `packages/`: código reutilizable.

No mezclar en un mismo PR un renombramiento masivo, un cambio funcional y una publicación de datos. Los movimientos de carpetas deben ser mecánicos y verificarse con `rg` y pruebas de instalación.
